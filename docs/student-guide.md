# Информация для студентов: Творческое программное задание (15 баллов)

## 📚 Общее описание

Это творческое задание на программирование, которое проверяет вашу способность разрабатывать качественный, практически полезный код с применением современных подходов DevOps и best practices.

**Ключевое отличие:** Вы не просто пишете код, вы создаете **полноценный проект** с правильной структурой, документацией, тестами и автоматизацией.

---

## 🎯 Что оценивается (15 баллов)

### 1️⃣ Полезность задачи (4 балла)
Ваш проект должен решать **реальную проблему** в одной из этих областей:
- 🎓 AI в образовании (анализ успеваемости, рекомендации, оценивание)
- 📊 Анализ образовательных данных
- 🔤 Обработка текста (NLP)
- 🤖 Рекомендательные системы
- 📈 Визуализация и аналитика

**Примеры хороших проектов:**
- Анализатор успеваемости студентов
- Детектор плагиата в работах
- Система рекомендации учебных материалов
- Классификатор сложности вопросов тестов
- Генератор вариантов заданий для студентов

### 2️⃣ Оформление репозитория (3 балла)
- ✓ `.gitignore` (соответствует типу проекта)
- ✓ `requirements.txt` (все зависимости с версиями)
- ✓ Логичная структура папок (`/src`, `/tests`, `/data`, `/docs`)
- ✓ Нет нежелательных файлов в репо

### 3️⃣ Работоспособность + CI/CD (4 балла)
- ✓ Код работает без ошибок
- ✓ GitHub Actions workflow настроен
- ✓ Проверка кода (PEP 8, flake8, black)
- ✓ Unit тесты работают
- ✓ Последний build имеет статус ✅ success

### 4️⃣ Качество документации (2 балла)
- ✓ README содержит: описание, инструкцию по установке, примеры
- ✓ Примеры кода работают и показывают результаты
- ✓ Описана структура проекта
- ✓ Текст ясный, без ошибок

### 5️⃣ Креативное использование CI/CD (2 баллов)
Workflow должен делать что-то полезное **сверх** обычной проверки кода:
- 📅 **Scheduled workflow** (автоматический запуск по расписанию, `cron`)
- 🎛️ **Workflow dispatch** (ручной триггер с параметрами)
- 📦 **Artifact upload** (сохранение результатов)
- 📝 **Data updates** (автоматическое обновление данных и коммит)
- 🚀 **Deploy** (публикация результатов на GitHub Pages)

**Пример:** Workflow, который каждый день генерирует отчет, сохраняет его и выкладывает на GitHub Pages.

## 🚀 Быстрый старт

### Шаг 1: Создайте репозиторий
```bash
git clone <your-repo>
cd your-project
```

### Шаг 2: Подготовьте структуру
```bash
mkdir -p src tests data scripts docs .github/workflows
touch .gitignore requirements.txt README.md
```

### Шаг 3: Заполните ключевые файлы

**`.gitignore`**
```
__pycache__/
*.pyc
.env
venv/
.vscode/
```

**`requirements.txt`**
```
numpy>=1.20.0
pandas>=1.3.0
pytest>=7.0.0
flake8>=4.0.0
black>=22.0.0
```

**`README.md`** (начните с шаблона из `quick-start.md`)

**`.github/workflows/tests.yml`** (начните с шаблона из `quick-start.md`)

### Шаг 4: Напишите код и тесты
- Основной код в `/src`
- Тесты в `/tests`
- Минимум 3-5 unit тестов

### Шаг 5: Добавьте креативный workflow
- Второй workflow с `schedule:` или `workflow_dispatch:`
- Например: генерация отчета, обновление данных, deploy

### Шаг 6: Протестируйте локально
```bash
pip install -r requirements.txt
pytest tests/
flake8 src
python src/main.py
```

### Шаг 7: Запушьте и проверьте Actions
- Перейдите на вкладку "Actions" на GitHub
- Убедитесь, что все workflow успешно прошли ✅

## 🤔 Часто задаваемые вопросы

### Q: Могу ли я использовать готовые библиотеки?
**A:** Да! Используйте `scikit-learn`, `pandas`, `numpy` и другие популярные библиотеки. Но основная логика должна быть ваша.

### Q: Сколько кода должно быть?
**A:** Минимум 200-300 строк основного кода (без тестов и комментариев). Качество важнее количества.

### Q: Что если я не знаю CI/CD?
**A:** Используйте готовые шаблоны из `quick-start.md`. Просто скопируйте и адаптируйте под ваш проект.

### Q: Могу ли я использовать готовые проекты как основу?
**A:** Да, но только как основу. Вы должны существенно модифицировать и улучшить проект. Просто копирование = 0 баллов.

### Q: Что такое "креативное использование CI/CD"?
**A:** Workflow, который делает что-то полезное для вашего проекта:
- Автоматическое обновление данных
- Генерация отчетов
- Развертывание результатов
- Запуск по расписанию
- Интерактивный триггер (workflow_dispatch)

### Q: Как добавить badge статуса?
**A:** В README добавьте:
```markdown
![Tests](https://github.com/YOUR_USERNAME/YOUR_REPO/workflows/Tests/badge.svg)
```

### Q: Когда сдавать?
**A:** **Дедлайн: 21/12/2025**. Время: 23:59. Используется последний коммит на `main` / `master` ветке.

### Q: Как сдать?
**A:** Отправьте ссылку на репозиторий в задание на [Курсе](https://elearn.urfu.ru)
