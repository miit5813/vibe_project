## Чек-лист для быстрой проверки (5 минут)

### ПОЛЕЗНОСТЬ ✓
- Откройте README
- Вопрос: "Это решает реальную проблему в ИИ/образовании/NLP?"
- ДА → 3-4 балла | НЕ ЯСНО → 1-2 балла | НЕТ → 0 баллов

### ОФОРМЛЕНИЕ ✓
```bash
# Проверьте:
$ git ls-tree -r HEAD | grep -E "(\.pyc|__pycache__|\.env)"  # Должно быть пусто
$ ls .gitignore requirements.txt                              # Должны быть
$ tree -L 2 src/ tests/ data/                                # Логичная структура?
```
- ВСЕ OK → 3 балла | Почти OK → 2 балла | Проблемы → 0-1 балл

### РАБОТОСПОСОБНОСТЬ ✓
- Откройте Actions tab на GitHub
- Последний run: 🟢 SUCCESS или 🔴 FAILED?
- SUCCESS → 3-4 балла | FAILED → 0-2 балла

### ДОКУМЕНТАЦИЯ ✓
- README имеет разделы: Description, Install, Usage, Examples?
- ДА → 2 балла | Частично → 1 балл | НЕТ → 0 баллов

### КРЕАТИВ CI/CD ✓
- Откройте `.github/workflows/` папку
- Есть ли файлы с `schedule:`, `workflow_dispatch:`, `upload-artifact:`?
- ДА → 2 балла | Базовый CI/CD → 1 балл | НЕТ → 0 баллов

## Сценарии для типичных вопросов

### Вопрос: "Считается ли это полезной задачей?"

**Да (3-4 балла), если:**
- Решает проблему в образовании, ИИ, NLP, рекомендациях, анализе данных
- Имеет практическое применение
- Не тривиальная реализация

**Нет (0-1 балл), если:**
- Еще один TODO app или Counter
- Не ясна цель проекта
- Очень узкое применение

### Вопрос: "Должны быть ли unit тесты?"

**Обязательно (3-4 балла), если:**
- Нужны тесты в workflow
- Минимум 3-5 тестов
- Покрытие > 70%

**Достаточно (2-3 балла), если:**
- Код работает, но тестов нет
- GitHub Actions проходит базовые проверки

### Вопрос: "Что считается "креативным CI/CD"?"

**Считается (2 балла), если:**
- Schedule (cron) запуск
- Workflow dispatch
- Artifact upload
- Git commits в workflow
- Deploy на GitHub Pages
- Notifications (Slack/email)

**Не считается (0-1 балл), если:**
- Только flake8/black проверка
- Только test run
- Нет никакой автоматизации сверх стандартного
