# Анализатор успеваемости студентов

## Описание
Этот проект — **Анализатор успеваемости студентов**, ориентированный на область **искусственного интеллекта в образовании и аналитики обучения**.  
Он считывает табличные данные о студентах (оценки, метрики активности) из CSV-файлов и вычисляет полезную аналитику:
- сводную статистику по группам и предметам,
- выявление студентов в группе риска,
- простые рекомендации на основе успеваемости.

Цель — предоставить **практически полезный инструмент** для преподавателей и исследователей, которые хотят быстро понять успеваемость своих студентов, используя воспроизводимый код на Python.

## Использование

Основная логика реализована в `src/performance_analyzer.py`.  
Вы можете **импортировать её как библиотеку** или использовать **точку входа через CLI** в `src/main.py`.

### Пример 1: Использование API Python
```python
from src.performance_analyzer import load_student_data, compute_basic_stats, detect_at_risk_students

df = load_student_data("data/sample_students.csv")
summary = compute_basic_stats(df)
at_risk = detect_at_risk_students(df, score_column="final_score", threshold=0.6)

print("Сводная статистика:")
print(summary)

print("\nСтуденты в группе риска:")
print(at_risk[["student_id", "final_score"]])
```

### Пример 2: Использование CLI
```bash
python -m src.main --input data/sample_students.csv --summary --at-risk --threshold 0.6
```

Ожидаемый вывод в консоли (упрощённый):

=== Студенты в группе риска (порог=0.60) ===

## Требования
Основные зависимости перечислены в `requirements.txt`:
- `pandas` для работы с табличными данными
- `numpy` для численных операций
- `pytest` и `pytest-cov` для тестов и покрытия кода
- `flake8` и `black` для проверки стиля и форматирования

Установите их с помощью:
```bash
pip install -r requirements.txt
```

## Тестирование

Запустите модульные тесты локально:
```bash
pytest tests/
```

Запустите тесты с отчётом о покрытии:
```bash
pytest --cov=src tests/
```

## CI/CD

Этот проект содержит **два workflow для GitHub Actions**:

- `tests.yml` — запускается при каждом `push` и `pull_request`:
  - устанавливает зависимости,
  - запускает проверки `flake8`,
  - запускает модульные тесты с покрытием.
- `daily-report.yml` — **креативный CI/CD workflow**, который может запускаться вручную или по расписанию:
  - запускает аналитику на файле `data/sample_students.csv`,
  - генерирует отчёт в формате Markdown в папке `reports/`,
  - загружает отчёт как артефакт сборки.

## Образовательный контекст и полезность

Этот проект относится к области **«аналитика образования / ИИ в образовании»** и может использоваться для:
- быстрого изучения наборов данных об успеваемости студентов,
- выявления групп риска,
- автоматического формирования ежедневных отчётов для преподавателей курсов,
